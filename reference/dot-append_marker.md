# Append a placeholder marker to rendered content

Attaches a marker (built via
[`.build_marker()`](https://wyuill.github.io/knittogether/reference/dot-build_marker.md))
to the rendered replacement body.

## Usage

``` r
.append_marker(
  body,
  token,
  output_mode,
  marker_mode,
  style_hidden,
  style_visible
)
```
