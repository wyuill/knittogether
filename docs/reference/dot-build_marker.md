# Build a placeholder marker span

Constructs a Pandoc-style span representing a placeholder marker with
styling applied according to `marker_mode` in
[`replace_placeholders()`](https://sturdy-giggle-wwjo5pk.pages.github.io/reference/replace_placeholders.md).

## Usage

``` r
.build_marker(token, marker_mode, style_hidden, style_visible)
```
